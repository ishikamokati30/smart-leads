# Smart Leads Dashboard

A MERN + TypeScript monorepo with:
- `client`: React + TypeScript + TailwindCSS + Vite
- `server`: Node.js + Express + TypeScript + MongoDB

## Setup

1. Clone the repository.
2. Run `npm install` from the root directory to install dependencies for both workspaces.
3. Copy `.env.example` to `.env` and fill in the environment variables.

## Running Locally

Run the following command from the root directory:

```bash
npm run dev
```

## Docker

Run the application using Docker Compose:

```bash
docker-compose up --build
```
